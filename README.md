# ProjectSignal

ProjectSignal is a prototype codename.

ProjectSignal is a 2D operational command game about asymmetric perception, imperfect information, logistics, reconnaissance, deception, and adaptation.

"Humans fight an intelligence war against an unknown biological system. Aliens fight an evolutionary war against an industrial system."

## Status
Design and prototype foundation.
