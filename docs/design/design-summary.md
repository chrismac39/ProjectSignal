ProjectSignal is a 2D operational strategy game focused on imperfect information.

Humans fight an intelligence war against an unknown biological system.

Aliens fight an evolutionary war against an industrial system.

The game revolves around:

Signal
→ Investigation
→ Confirmation
→ Action
→ Assessment

The game contains three battlefield realities:

Human Reality
Alien Reality
Omniscient Reality

Players never see Omniscient Reality during gameplay.

Combat exists primarily to support the information game.

The world is an active ecological system containing wildlife, migration, geography, and environmental noise.

Current prototype goal:

Prove that Human Reality, Alien Reality, and Omniscient Reality create interesting gameplay before implementing combat, resources, or victory conditions.
