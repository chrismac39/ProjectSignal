# Open Questions

## Resolved For Prototype 0

- Turn model: deterministic WEGO.
- Runtime: standalone .NET console application.
- Presentation: technical logs and Markdown AAR; no visualization layer.
- Scenario authoring: C# fixtures until the domain schema stabilizes.
- Player control: scripted decisions before an interactive commander interface.
- Replay granularity: immutable chronological turn records plus turn-boundary snapshots.
