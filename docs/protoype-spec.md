# Prototype Specification

## Objective

Validate Human Reality, Alien Reality, and Omniscient Reality.

Nothing else matters yet.

---

## Included

* One map
* Terrain
* Wildlife
* Human visibility layer
* Alien visibility layer
* Omniscient visibility layer
* One human scout
* One alien scout
* One signal type
* One investigation mechanic
* Replay timeline

---

## Excluded

* Combat
* Resources
* Production
* Logistics
* Titans
* Victory conditions
* Multiplayer
* AI opponents

---

## Success Criteria

A player can:

1. Observe a signal.
2. Form a hypothesis.
3. Investigate.
4. Discover the truth.
5. Review the difference in replay.

If this creates interesting decisions, proceed to Milestone 1.
If not, redesign before expanding scope.
